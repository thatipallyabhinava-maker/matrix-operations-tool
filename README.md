# Matrix Operations Tool

# Introduction

Matrix Operations Tool is a simple Python application used to perform basic matrix operations.

The user can enter matrices and select the operation they want to perform.

# Operations

The application performs:

* Addition
* Subtraction
* Multiplication
* Transpose
* Determinant

# Technologies Used

* Python
* NumPy
* Tkinter
* VS Code

# How to Install

Install NumPy using:

bash
pip install numpy


Or:

bash
pip install -r requirements.txt


# How to Run

Open the project folder in VS Code.

Open the terminal and run:

bash
python main.py


# How to Enter a Matrix

Enter each row on a separate line.

Example:

text
1 2
3 4


This represents:

text
1  2
3  4


 Example

Matrix A:

text
1 2
3 4

Matrix B:

text
5 6
7 8


Addition gives:

text
6 8
10 12


Multiplication gives:

text
19 22
43 50


Transpose of Matrix A:

text
1 3
2 4

Determinant of Matrix A:

text
-2
